For Activity 4a, I completed a Cookie class with flavor, size and position properties. Arrow keys move the cookie using a move() method, and clicking calls randomFlavor() to change its flavor and colour. I added strawberry and matcha to the chocolate, vanilla and oatmeal options.
For Activity 4b, I made an Agent class where each circle moves, bounces off the edges, shifts colour and grows over time. Clicking adds a new agent, C clears them all, and any agent reaching size 100 is removed to look like it pops!
